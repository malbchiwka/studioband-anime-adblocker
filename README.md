# StudioBand & Anime AdBlocker для Firefox

Специализированное расширение для браузера **Mozilla Firefox**, полностью блокирующее рекламные видеовставки (прероллы, мидроллы посреди серии, пауза-роллы, VAST/VPAID), баннеры и кликандеры при просмотре аниме на **[studiobandme.ru](https://www.studiobandme.ru/)** (включая плееры CDNVideoHub и Kodik).

---

## 🎯 Что блокирует расширение

1. **Видео-реклама во время серии (Midroll / Прероллы)**:
   - В плеере **CDNVideoHub** (основная вкладка): на лету очищает VAST-манифесты и рекламные очереди (`adPod`), благодаря чему плеер начинает серию сразу и не прерывает просмотр рекламными вставками в середине эпизода.
   - В плеере **Kodik** (альтернативные вкладки озвучек): перехватывает ответ `/ftor` и вырезает рекламные блоки VAST (Buzzoola и др.), убирая навязчивую рекламу перед серией и во время неё.
2. **Кликандеры и всплывающие окна (Pop-under)**:
   - Блокирует скрипты `vak345.com`, `trafficbass.com` и попытки открыть рекламные сайты (букмекеры, казино) при клике на плеер.
3. **Баннеры и трекеры**:
   - Блокирует рекламные блоки Яндекс RTB (`yandex_rtb_*`), AdFox, метрики и фоновые трекеры.

## 🚀 Инструкция по установке в Firefox

### Способ 1: Быстрая установка (работает в любом Firefox)

1. Откройте **Firefox**.
2. В адресную строку вставьте:
   ```text
   about:debugging#/runtime/this-firefox
   ```
   и нажмите **Enter**.
3. Нажмите кнопку **«Загрузить временное дополнение...»** (Load Temporary Add-on).
4. В открывшемся окне выберите файл:
   ```text
   manifest.json в папке репозитория
   ```
   *(либо архив `studioband-anime-adblocker.zip` / `.xpi`)*.
5. Готово! Расширение сразу станет активным. На панели браузера появится иконка щита с логотипом.

> 💡 **Совет**: Временное дополнение работает до перезапуска Firefox. Для постоянной работы в стандартном Firefox достаточно раз в сессию подключать его, либо использовать Firefox Developer Edition / Nightly.

---

### Способ 2: Постоянная установка (в Firefox Developer Edition / Nightly)

1. Откройте `about:config` и переключите параметр:
   ```text
   xpinstall.signatures.required = false
   ```
2. Откройте `about:addons` (или нажмите `Ctrl + Shift + A`).
3. Нажмите на значок шестерёнки вверху справа и выберите **«Установить дополнение из файла...»**.
4. Выберите готовый файл:
   ```text
   studioband-anime-adblocker.xpi
   ```

## 🛠 Архитектура решения

Расширение использует многоуровневую защиту:

- **Сетевой уровень (Firefox `filterResponseData`)**:
  В `background.js` встроен нативный стрим-фильтр Firefox, перехватывающий сетевые ответы API плееров (`plapi.cdnvideohub.com` и `/ftor`). Он декодирует входящий JSON, обнуляет структуру `vast` и `adPod`, и отправляет плееру очищенные данные.
- **Уровень контекста страницы (`inject.js`)**:
  Внедряется в основной контекст страницы (`window`) до загрузки остальных скриптов. Перехватывает `fetch` и `XMLHttpRequest`, нейтрализует глобальные объекты `advertScript` и `playerSettings.vast`.
- **DOM и авто-пропуск (`content.js` + `blocker.css`)**:
  Скрывает баннеры без сдвигов верстки, отслеживает элементы `<video>` (при обнаружении рекламного фрагмента мгновенно перематывает его в конец) и автоматически нажимает кнопки «Пропустить рекламу».
- **Интерфейс управления (`popup.html` / `popup.js`)**:
  Показывает в реальном времени счетчики заблокированных видео-вставок, баннеров и трекеров, а также позволяет временно включить/отключить фильтрацию.
